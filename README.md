# C Programming Exercises & Projects

A structured repository containing foundational C programming concepts, exercises, and mini-projects. This repo serves as a personal log of learning progress, covering everything from core syntax to functional applications.

## 📂 Repository Structure

The project is organized into logical directories based on topics:

* **`basics/`**: Fundamental concepts including input/output, arithmetic operations, basic data types, and simple geometry calculations.
* **`conditionals/`**: Programs implementing decision-making logic using `if`, `else if`, and `else` statements.
* **`loops/`**: Examples demonstrating iterative logic using `for`, `while`, and `do-while` loops.
* **`functions/`**: Modular code examples showcasing pass-by-value, math operations, and utility functions (e.g., swapping, factorials).
* **`arrays/`**: Programs focused on continuous memory allocation, array traversal, searching, and manipulation.
* **`mini_projects/`**: Small, practical console applications combining multiple concepts (e.g., calculators, billing systems).
